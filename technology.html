Kortexis is a deep-tech platform currently in the prototype validation phase. The architecture described below reflects the system design currently being implemented and tested using GPU cloud infrastructure.

Graph Neural Networks for Non-Linear Structural Mechanics

Kortexis implements a discretized Lagrangian approach to predict nodal displacement in non-linear dynamic crash events. By treating the Finite Element mesh as a graph structure \( G = (V, E) \), we perform message passing operations to approximate the solution of partial differential equations far more efficiently than traditional explicit time-integration approaches.

01. Physics-Informed Loss Landscape

To mitigate "hallucinations" common in pure data-driven models, our training pipeline enforces physical constraints via the loss function. The total loss \(\mathcal{L}_{total}\) is defined as:

$$ \mathcal{L}_{total} = \lambda_{data} \mathcal{L}_{MSE} + \lambda_{phy} (\mathcal{L}_{mass} + \mathcal{L}_{momentum} + \mathcal{L}_{energy}) $$

This ensures that the predicted deformation fields respect the conservation of momentum at each time step \(t\):

$$ \rho \left( \frac{\partial \mathbf{v}}{\partial t} + \mathbf{v} \cdot \nabla \mathbf{v} \right) = -\nabla p + \nabla \cdot \mathbf{T} + \mathbf{f} $$

02. Proposed Infrastructure Stack

The Kortexis platform is being architected to leverage Google Cloud's HPC capabilities. The current development roadmap targets the following stack:

Training Pipeline (Planned Architecture)

  • ▸ Framework: PyTorch Geometric (PyG)
  • ▸ Compute Targets: GCP A2/A3 VMs (NVIDIA A100/H100)
  • ▸ Orchestration: Kubeflow Pipelines on GKE
  • ▸ Data: TFRecord format on Cloud Storage

Inference Engine

  • ▸ Runtime: ONNX Runtime (TensorRT)
  • ▸ API: FastAPI / gRPC with Protobuf
  • ▸ Container: Docker (Distroless/Debian11)
  • ▸ Hardware: Optimized for NVIDIA L4 Tensor Core
