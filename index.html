Enterprise Deployment

The Kortexis Solver is architected as a containerized software artifact designed for secure, air-gapped environments. We support flexible deployment models to meet OEM data sovereignty requirements.

  • ✓ On-Premise GPU Cluster Integration
  • ✓ Virtual Private Cloud (VPC) Deployment
  • ✓ Federated Learning Capable
deployment_config.yaml YAML
image: "kortexis/solver:v2.4-release"
license_key: ${OEM_LICENSE_KEY}
infrastructure:
  provider: "google-cloud"
  accelerator: "nvidia-l4"
  replicas: 8
security:
  network_policy: "deny-egress"
